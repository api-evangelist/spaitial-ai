## API Reference

> Developer REST API for SpAItial. Authentication, errors, rate limits, and OpenAPI reference.

- [Authentication](https://docs.spaitial.ai/api/authentication.md): How to authenticate to the SpAItial Developer API with a bearer API key.
- [Credits and Billing](https://docs.spaitial.ai/api/credits-billing.md): How credits, plans, and billing work for the SpAItial Developer API.
- [Errors](https://docs.spaitial.ai/api/errors.md): HTTP status codes, error envelope shape, and stable error codes returned by the SpAItial Developer API.
- [Files](https://docs.spaitial.ai/api/files.md): Upload, list, and reuse image files with the SpAItial Developer API.
- [Getting Started](https://docs.spaitial.ai/api/getting-started.md): Quick overview of the SpAItial Developer API — base URL, prerequisites, and your first request.
- [LLM Skills](https://docs.spaitial.ai/api/llm-skills.md): Self-contained reference for AI coding assistants integrating with the SpAItial Developer API.
- [MCP Server](https://docs.spaitial.ai/api/mcp-server.md): Use the SpAItial Developer API from Cursor, Claude, VS Code, and other AI agents via the hosted Model Context Protocol (MCP) server.
- [Moderation](https://docs.spaitial.ai/api/moderation.md): How SpAItial screens API inputs before generation.
- [Panorama Editing](https://docs.spaitial.ai/api/panorama-editing.md): Edit a world's panorama with a prompt, iterate, then create a new world from the result.
- [Rate Limits](https://docs.spaitial.ai/api/rate-limits.md): Per-key rate limiting on the SpAItial Developer API, including headers and bucket layout.
- [files](https://docs.spaitial.ai/api/reference/files.md): files
- [models](https://docs.spaitial.ai/api/reference/models.md): models
- [SpAItial Developer API](https://docs.spaitial.ai/api/reference/spaitial-developer-api.md): Programmatic API for generating 3D worlds. See the [Getting Started guide](https://docs.spaitial.ai/api/getting-started) for authentication and usage examples.
- [List files uploaded by this API key](https://docs.spaitial.ai/api/reference/v-1-files-list-files.md): List files uploaded by this API key
- [Upload a file for later use in world generation](https://docs.spaitial.ai/api/reference/v-1-files-upload-file.md): Upload a file for later use in world generation
- [List available models](https://docs.spaitial.ai/api/reference/v-1-models-list-models.md): List available models
- [Download a panorama image](https://docs.spaitial.ai/api/reference/v-1-panoramas-download-panorama.md): Redirects (302) to a short-lived signed download URL (~5 minutes). Re-hit this endpoint when it expires.
- [Edit a panorama and return the updated panorama](https://docs.spaitial.ai/api/reference/v-1-panoramas-edit-panorama.md): Fetches the panorama behind the source (a request_id / world_id you created, or a panorama_id from a previous edit), applies the prompt + optional reference images, and returns the new panorama. Iterate by passing the returned panorama_id back in as the source; create a world from the final panorama via POST /v1/worlds with input { type: 'panorama_id' }.
- [Get a panorama](https://docs.spaitial.ai/api/reference/v-1-panoramas-get-panorama.md): Get a panorama
- [List panoramas created by this API key](https://docs.spaitial.ai/api/reference/v-1-panoramas-list-panoramas.md): List panoramas created by this API key
- [Cancel a job](https://docs.spaitial.ai/api/reference/v-1-worlds-cancel-job.md): Cancel a job
- [Start or retrieve an export for a completed job](https://docs.spaitial.ai/api/reference/v-1-worlds-create-export.md): Export artifacts from worlds. Supports just collision meshes for now. Mesh exports can take several minutes, so ensure to check the status before requesting the download URL.
- [Create a new world generation job](https://docs.spaitial.ai/api/reference/v-1-worlds-create-job.md): Create a new world generation job
- [Get export status](https://docs.spaitial.ai/api/reference/v-1-worlds-get-export.md): Returns export status. When ready, the response includes a backend proxy download_url. Add ?download=1 to this same endpoint to redirect to a short-lived signed file URL.
- [Get full job result](https://docs.spaitial.ai/api/reference/v-1-worlds-get-job-result.md): Get full job result
- [Get job status](https://docs.spaitial.ai/api/reference/v-1-worlds-get-job-status.md): Get job status
- [Download the panorama artifact for a completed job](https://docs.spaitial.ai/api/reference/v-1-worlds-get-panorama-download.md): Redirects (302) to a short-lived signed download URL. The URL is valid for ~5 minutes; re-hit this endpoint when it expires.
- [Download the splat artifact for a completed job](https://docs.spaitial.ai/api/reference/v-1-worlds-get-splat-download.md): Redirects (302) to a short-lived signed download URL. The URL is valid for ~5 minutes; re-hit this endpoint when it expires.
- [List exports for a completed job](https://docs.spaitial.ai/api/reference/v-1-worlds-list-exports.md): List exports for a completed job
- [List jobs created by this API key](https://docs.spaitial.ai/api/reference/v-1-worlds-list-jobs.md): List jobs created by this API key
- [Update world visibility or title](https://docs.spaitial.ai/api/reference/v-1-worlds-update-world.md): Update world visibility or title
- [worlds](https://docs.spaitial.ai/api/reference/worlds.md): worlds
- [Validation](https://docs.spaitial.ai/api/validation.md): Configure image suitability validation for v1 world generation.
